# ADR 0020　管理者の認証と画面を利用者から分ける

- Status: Accepted
- Date: 2026-11-23
- Linear: LET-15、LET-28

管理者は事前に用意したアカウントで、利用者全体の注文や献立を扱う。利用者は自分のマイページと注文だけを扱う。管理権限を利用者登録の入力項目から付与できる構造を避けるため、管理者を専用テーブルに保存し、Deviseのスコープを分ける。

管理用URLを `/admin` にまとめる。管理業務のコントローラーは `Admin::BaseController` を継承し、アクション実行前に管理者としての認証を確認する。管理者のセッションにはログインとログアウトだけを公開する。利用者のマイページはセッションの本人から取得する。今後、注文など利用者ごとのレコードを開くときも、ログイン中の利用者が所有するレコードから検索する。

同じブラウザでそれぞれの資格情報を入力した場合、ログアウトは操作した側のスコープだけを終了する。管理者登録はシードで行い、繰り返し実行しても既存のパスワードを上書きしない。

現行の権限は利用者本人と管理者の2種類であり、既存のDeviseとActive Recordで判定できる。役割や個別の操作権限が増えた時点で、認可ライブラリを再検討する。
