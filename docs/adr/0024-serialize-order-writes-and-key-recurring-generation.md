# ADR 0024 注文の受付を直列化し、生成元と対象日で二重生成を防ぐ

- Status: Proposed
- Date: 2026-11-25
- Linear: LET-19・LET-34・LET-36・LET-39・LET-40

注文を保存するときは、利用者と日別献立をこの順でロックする。利用者のロックは別々の献立でも同日の合計個数を守るために使う。献立のロックは、同じ献立を注文する利用者が手動注文枠を同時に使うのを防ぐために使う。定期注文の生成も両方のロックを取り、利用者の同日上限を確認する。定期生成では残数の確認を省く。

定期注文は生成元設定を参照し、生成対象日を保存する。設定の弁当タイプを編集した後に同じ日を指定すると、候補の献立IDが変わる場合がある。そこで生成元設定と対象日の組に一意制約を設ける。キャンセル済みも一意制約の対象に含める。

生成対象日は複合外部キーで参照先の献立の提供日と一致させる。定期注文が参照する日別献立の提供日を変更すると、生成済みの注文が別の日へ移るため、日付の編集を拒否する。手動注文の生成元設定と対象日は空欄にする。
