# ADR 0010: 本人アカウントの非公開リポジトリで準備する

- Status: Accepted
- Date: 2026-11-16
- Linear: LET-21

## Context

提出にはGitHub URLが必要。公開範囲は指定されておらず、課題や実装を広く公開する必要はない。RenderとCIの連携先を先に用意する。

## Decision

- 本人のGitHubアカウントに`Lettuce222/hirudoki`を非公開で作成する。
- 公開URL: https://github.com/Lettuce222/hirudoki （参照にはアクセス権が必要）。
- アプリ用ディレクトリをリポジトリルートにする。
- master.key、環境変数、DB接続情報、アップロード画像、ローカルGem、稼働中の時計状態はコミットしない。
- mainへ直接force pushしない。以後はブランチとPR、CIを経由する。利用プランが保護ルールの強制に対応するかはGitHub上で確認し、運用ルールとサーバー側強制を区別する。
- 提出前に採点者のGitHubアカウント/指定アクセス方式を確認し、第三者視点の参照確認をLET-46で実施する。現時点で採点者のアクセス完了とは扱わない。

## Alternatives considered

- 最初からpublic: 採点者への参照は容易だが、不特定多数への公開は不要なため採用しない。
- 最後にリポジトリを作る: 先行デプロイとCI連携を遅らせるため採用しない。
- 組織リポジトリ: 今回は個人の選考課題であり、所属組織のアクセス権を使う必要がない。

## Consequences

Renderには対象の個人リポジトリだけの権限を与える。採点者への共有が別途必要になるが、提出直前に取りこぼさないようLET-46に残す。
